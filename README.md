# 📚 Smart Study Planner

A simple and responsive study planner built with HTML, CSS, and JavaScript.

The Smart Study Planner helps students organize study tasks, track completed work, and monitor their progress.

## ✨ Features

- ➕ Add study tasks
- 📚 Select a subject
- 📅 Choose a study date
- 🔥 Set task priority
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📊 Track study progress
- 💾 Save tasks using localStorage
- 🔍 Filter tasks by All, Pending, or Completed
- 📱 Responsive mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
